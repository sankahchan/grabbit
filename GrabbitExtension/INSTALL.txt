Grabbit Web Grabber — Browser Extension
========================================

Install (Chrome / Edge / Brave)
-------------------------------
1. Open  chrome://extensions  (or edge://extensions) in your browser.
2. Turn on "Developer mode" (top-right toggle).
3. Click "Load unpacked" and select the folder that contains this file.
4. Open the Grabbit app. It connects the extension automatically on launch
   (Grabbit 1.3.0+), including the native helper.

Updating
--------
Easiest: open the Grabbit app -> Grabber tab -> "Update extension".
It downloads the latest package and installs it for you; you only click
Reload afterwards.

Manual: replace this folder's contents with a newer ZIP from
https://github.com/sankahchan/grabbit/releases (grabbit-extension-latest.zip),
then click the Reload (circled arrow) icon on the extension card in
chrome://extensions.

Troubleshooting
---------------
- Popup says "native host: unavailable"
  -> Update the Grabbit app (1.3.0 or newer). It installs the helper and
     writes the browser host manifest automatically. If you use a custom
     extension ID, run:
     ./GrabbitExtension/native-messaging/install-host.sh <extension-id>

- Nothing detected on a page
  -> Make sure the video/photo is visible or playing, then open the popup.
     On Telegram Web, open the media in the viewer.

- After updating files, changes did not apply
  -> chrome://extensions -> Reload (circled arrow) on the Grabbit card.

Privacy
-------
No data leaves your computer. URLs, page metadata and (for protected
downloads) login cookies go only to the Grabbit app on your Mac through
Chrome's native messaging API. No analytics, no tracking.
